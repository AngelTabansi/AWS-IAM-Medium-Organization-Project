# AWS IAM — Medium-Sized Organization Project

## Project Overview

This project demonstrates the design and implementation of AWS Identity and Access Management (IAM) for a fictional medium-sized organization, AdescoTechHub Ltd.

The goal was to organize user access, manage permissions, and apply security best practices using AWS IAM.

## Objectives

- Create and organize IAM users and groups.
- Apply permissions using IAM policies.
- Implement Multi-Factor Authentication (MFA).
- Explore IAM roles and access management.
- Apply the principle of least privilege.

## AWS Services and Concepts

- **AWS IAM:** Identity and access management.
- **IAM Users and Groups:** Organizing identities and permissions.
- **IAM Policies:** Defining permitted actions and resources.
- **MFA:** Adding an extra layer of account security.
- **IAM Roles:** Managing permissions for trusted entities.

## Skills Demonstrated

- AWS Console navigation
- Identity and access management
- User and group administration
- Permission and policy management
- Cloud security fundamentals
